# dsh-screenshot · 截图标注

给 DeepSeek Harness 的原生截图标注插件：弹全屏窗口，框选、标注，回车把选区送进输入框。

**仅支持 Windows。**

## 安装

设置 → 插件 → 添加插件，选本目录，刷新页面。

## 使用

| 操作 | 效果 |
|---|---|
| 相机按钮 / `Ctrl+Alt+Q` | 截图（快捷键全局生效，固定组合） |
| 拖动 | 框选 |
| 矩形/椭圆/箭头/画笔/文字/马赛克 | 标注 |
| `Enter` / ✓ | 图片进输入框（不自动发送） |
| 复制按钮 | 进剪贴板，不进输入框 |
| `Esc` / 右键 / ✕ | 取消 |
| `Ctrl+Z` | 撤销 |
| 「隐藏当前窗口」菜单 | 是否连 Harness 窗口一起截（按钮和快捷键共用） |

## 限制

- 仅 Windows。
- 快捷键固定 `Ctrl+Alt+Q`，无设置入口；被占用时自动换一个可用组合。
- 「隐藏当前窗口」是把窗口移开再移回。
