<h1 align="center">dsh-screenshot · 截图标注</h1>

<h3 align="center">简体中文 &nbsp;·&nbsp; <a href="README-en.md">English</a></h3>

<p align="center"><b>给 DeepSeek Harness 窗口补上手动截图</b><br>精简版窗口没有截图功能，这个插件把它补上：弹全屏窗口，框选、标注，回车把选区送进输入框。<br>仅支持 Windows。</p>

## 安装

设置 → 插件 → 添加插件，选本目录，刷新页面。

## 使用

| 操作 | 效果 |
|---|---|
| 相机按钮 / `Ctrl+Alt+Q` | 截图（快捷键全局生效，固定组合） |
| 拖动 | 框选 |
| 矩形/椭圆/箭头/画笔/文字/马赛克 | 标注 |
| `Enter` / ✓ | 图片进输入框（不自动发送） |
| 复制按钮 | 进剪贴板，不进输入框 |
| `Esc` / 右键 / ✕ | 取消 |
| `Ctrl+Z` | 撤销 |
| 「隐藏当前窗口」菜单 | 仅影响按钮：是否把 Harness 窗口最小化后再截；快捷键不做处理，直接截当前屏幕 |

## 限制

- 仅 Windows。
- 快捷键固定 `Ctrl+Alt+Q`，无设置入口；被占用时自动换一个可用组合。
- 快捷键直接截当前屏幕，不隐藏窗口；「隐藏当前窗口」只对相机按钮生效（最小化后再截）。
